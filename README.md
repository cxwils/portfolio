# Portfolio

Next.js (App Router) + TypeScript + Tailwind CSS. Static site, deploys free on Vercel.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Edit your content

All text, links and projects live in `src/data/site.ts`. Fields marked `TODO` are empty on purpose, and empty links are hidden until you fill them in.

To add a project screenshot, put the image in `public/projects/` and set `image: "/projects/your-file.png"` on that project.

## Deploy

Push to GitHub, then import the repo at vercel.com. No settings needed.
